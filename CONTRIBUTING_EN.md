# Contributing Guide

Thank you for contributing to **IELTS Reading Trainer**! There are two ways to help.

> 中文版：[CONTRIBUTING.md](CONTRIBUTING.md)

## 1. Contributing code

1. Fork this repo and create a branch named `feat/xxx` or `fix/xxx`
2. Make sure all tests pass before pushing:
   ```bash
   node test/engine_test.js        # 28 assertions: grading / locating / analysis
   node test/generator_test.js     # 47 assertions: question generation / answer derivability
   node test/dict_test.js          # 18 assertions: stemming / derivatives / coverage
   ```
   Browser E2E (needs a local Chrome; replace `chrome` with your Chrome binary):
   ```bash
   chrome --headless --disable-gpu --no-sandbox \
     --virtual-time-budget=8000 --dump-dom "file://<repo>/test/e2e-auto.html" | grep -o 'E2E \[[^<]*'
   ```
   > CI runs all of these automatically on every push and PR.
   > See [.github/workflows/tests.yml](.github/workflows/tests.yml).
3. Write commit messages that clearly state **what changed and why** (Chinese or English)
4. Open a Pull Request describing your change and test results

## 2. Contributing articles & questions (grow the shared bank)

Anyone can turn an English article they have the right to share into practice questions:

1. Open the app → top-right 「＋ Import」
2. Paste the article (blank lines separate paragraphs), then pick a question source:
   - **Auto-generate**: the offline rule engine produces TFNG / gap-fill / heading questions instantly
   - **Manual**: enter each question's stem and answer yourself
   - **Mixed**: auto first, then fill in manually
3. Choose 「**Contribute to the shared bank**」 and tick **all three confirmations**:
   - you hold the rights to the article (original / public domain / licensed) —
     **never scrape full text from commercial sites or publications**
   - the questions are your own or generated by this tool —
     **never copy questions from commercial prep sites**
   - the article contains no private, confidential, or inappropriate content
4. Fill in your contributor handle and the license (CC BY 4.0 / CC0 / licensed republication)
5. Click 「Export pack」 to get `reading-pack-YYYY-MM-DD.json`
6. Submit it via a PR into the `packs/` directory, or send it to a maintainer

Maintainers verify the declarations before merging so everyone can use it via
「Import pack」.

## Not accepted

- Articles or questions copied from commercial publications or prep sites (copyright risk)
- Partial "candidate-recalled" real-exam material (incomplete, unreliable answers)
- Anything containing private, confidential, or inappropriate content

## Pack format (`format: "ielts-reading-pack"`, version 1)

```json
{
  "format": "ielts-reading-pack",
  "version": 1,
  "generator": "IELTS Reading Trainer",
  "createdAt": "2026-10-12T00:00:00.000Z",
  "exams": [
    {
      "id": "unique-id",
      "title": "My Article-Test 1-Passage 1",
      "titleCn": "中文副标题",
      "book": "我的文章", "test": 1, "passage": 1,
      "difficulty": "Easy|Medium|Hard",
      "series": "文章导入 · 自动出题",
      "source": "contributor xxx · CC BY 4.0",
      "level": "自定义", "minutes": 20,
      "tags": ["environment"],
      "intro": "简介",
      "contribution": {
        "contributor": "xxx",
        "license": "CC BY 4.0",
        "declaredAt": "2026-10-12T00:00:00.000Z",
        "declaration": "copyright-ok;questions-original-or-tool-generated;no-privacy"
      },
      "sections": [
        {
          "id": "s1",
          "title": "READING PASSAGE 1",
          "paragraphs": [{ "id": "A", "text": "..." }],
          "questionGroups": [
            {
              "id": "g1", "type": "tfng|mcq|gapfill|matching|headings|multi",
              "instruction": "instructions",
              "options": ["TRUE", "FALSE", "NOT GIVEN"],
              "pool": ["A", "B"], "poolLabels": ["A  Dr X"],
              "headings": ["i  Heading one"],
              "questions": [
                {
                  "no": 1, "stem": "stem", "answer": "TRUE",
                  "answers": ["备选答案1"], "options": ["A;B;C;D"],
                  "keyPara": "B", "keySentence": "must appear verbatim in the article",
                  "keySentenceCn": "translation", "explain": "explanation",
                  "trap": "trap note", "words": ["keyword"]
                }
              ]
            }
          ]
        }
      ],
      "vocabulary": [{ "word": "humble", "pos": "adj.", "meaning": "不起眼的", "sentence": "..." }]
    }
  ]
}
```

> `keySentence` must appear **verbatim** in the article (the report page highlights it).
> Auto-generated questions satisfy this by construction; manually typed ones are located
> automatically by the app when possible.
