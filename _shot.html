使用说明 How it works
1. 选题在题库卡片上点击任意试卷，默认进入「练习模式」（不限时、每题可看定位提示）；想做整套限时训练，从右上角进入「考试模式」。
2. 做题左侧文章、右侧题目。判断题 / 选择题 / 填空题 / 匹配题 / 标题匹配题均支持，鼠标或触屏直接作答。
3. 分析交卷后生成分析报告：正确率与 Band 估算、各题型得分、每道错题的原文定位句（点击可在文章中高亮）、关键句中英对照、同义替换线索与陷阱类型、本题重点词汇。
4. 巩固错题自动进入「练习记录 → 错题本」，重点词可加入「生词本」；点「复制报告」可把成绩与错题发给 AI 做进一步深度分析。
5. 导入真题点右上角「导入真题」，填好书卷（如 C21）、Test/Passage 编号和难度，按空行分段粘贴文章、逐题录入题干与答案，系统自动完成段落编号、原句定位与陷阱标注。真题来源于你自己已购的剑桥雅思书籍，仅供个人学习；想要逐题精解，把文章内容发我即可帮你写成完整解析。

🌐 社区题库

从项目 GitHub 仓库的 packs/ 目录在线阅读并导入。所有内容由社区贡献，授权方式见每条来源标注；知识产权归各贡献者，本项目仅提供索引与导入通道。
关于权限（请先读）：前端代码是公开的，写死任何"管理员密码"都等于没有密码， 所以本应用不使用密码，而是用你自己的 GitHub 令牌来获得写权限。
  • 令牌只保存在你当前这台浏览器的 localStorage，不会上传到任何地方，也不会进代码仓库
  • 请使用细粒度令牌（Fine-grained PAT）：Repository access 只勾选 l458022/ielts-reading-trainer，Permissions 只给 Contents: Read and write
  • 创建入口：GitHub → 头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  • 每次删改都会在仓库留下一条提交记录（可审计、可回滚）；公共电脑上用完请点「清除令牌」
✅ 管理模式已开启：上方每个题库包会多出「编辑」「删除」按钮。
